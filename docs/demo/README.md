# Buildathon demo package

This directory contains the 90-second NutriScan AI buildathon demo script,
storyboard, and rendered media assets.

## Deliverables

- [`NutriScan-AI-Buildathon-Demo.mp4`](NutriScan-AI-Buildathon-Demo.mp4) — 1280×720,
  90-second YouTube-ready demo with voiceover.
- [`buildathon-demo-script.md`](buildathon-demo-script.md) — narration and recording
  direction.
- [`storyboard.csv`](storyboard.csv) — time-coded shots, visuals, and on-screen copy.
- [`youtube-metadata.md`](youtube-metadata.md) — suggested upload title, description,
  chapters, and tags.

The demo presents the application as an explainable field-screening prototype.
It deliberately avoids claiming laboratory-equivalent accuracy, automated photo
diagnosis, or feed-safety certification.
