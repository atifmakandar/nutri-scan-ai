# Source basis — SIH presentation

The implementation in this repository is based on the uploaded project presentation for Smart India Hackathon 2026, PS 26111.

Key source concepts used:
- Problem: rapid, portable and digitally enabled feed/silage quality assessment.
- Nutri-Scan AI: mobile app + portable tester.
- Inputs: camera, NIR spectroscopy, moisture, pH, temperature/humidity sensors and ESP32.
- Processing: data cleaning, preprocessing, feature extraction, multi-source data fusion and AI/ML analysis.
- Outputs: moisture, dry matter, protein, fiber, pH, temperature, fermentation quality, spoilage risk and nutritional score.
- Feasibility: ESP32 + Raspberry Pi, modular sensors, cloud integration and laboratory-reference calibration.
- Users: dairy farmers, cooperatives, FPOs and feed mills.
- Scale: farm → cooperative → district → state.

Source document: `final ppt.pptx` supplied in the chat.
